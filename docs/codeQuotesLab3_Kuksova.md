# блоки кода и цитаты

## inline-код

команда `git status` показывает состояние репозитория.

## блок кода с подсветкой

```csharp
Console.WriteLine("Введите имя: ");
string name = Console.ReadLine();
Console.WriteLine($"Привет, {name}");
```

## блок кода без языка

```
просто текст
внутри блока
без подсветки
```
