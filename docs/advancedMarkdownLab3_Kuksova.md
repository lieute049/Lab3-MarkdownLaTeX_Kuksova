## alert-блок

> [!TIP]
> для экранирования спецсимволов используй обратный слэш `\`. например, чтобы написать `*курсив*` без форматирования — `\*курсив\*`.

## escape-символы

- заголовок без форматирования: `\# это не заголовок`
- звёздочка как текст: `\*просто звёздочка\*`
