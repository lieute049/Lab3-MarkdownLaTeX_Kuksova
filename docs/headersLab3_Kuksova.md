## лабораторная №3. markdown-разметка и latex в документации

#### что такое markdown

markdown — лёгкий язык разметки для README, документации, отчётов и заметок. просто пишется, хорошо читается и в сыром виде, и после рендеринга. поддерживается GitHub, VS Code и другими платформами.

#### где применяется

- README и документация проектов
- блоги и веб-разработка
- статические сайты (GitHub Pages, Hugo)
- заметки и презентации
- GitHub, GitLab, GitFlic

#### зачем нужен разработчикам

markdown экономит время: текст пишется обычными символами, легко читается, а потом превращается в HTML или PDF без сложных редакторов. удобно для README, комментариев и заметок.
