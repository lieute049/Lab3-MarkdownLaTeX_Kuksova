# введение

markdown — простой язык разметки для быстрого форматирования текста. легко превращается в HTML, используется для документации, постов и заметок.

---

# основные возможности markdown

- заголовки
- списки
- жирный и курсив
- ссылки и картинки
- таблицы
- блоки кода
